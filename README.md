# 🚀 [Pet love]

## 📌 Descrição do Projeto
[Esta é uma aplicação web desenvolvida com intuito ficticio de adoção de animais, permitindo ao usuário escolher, preencher formulários, com links diretos para rede social com intuito de incentivar a adoção, com descritivos claros e fofos de pets.]

## 🤖 Documentação do Uso de Inteligência Artificial (IA)

### 1. Prompts
Durante a criação do projeto, a IA foi utilizada para auxiliar na resolução de problemas, estruturação do código e complementação de ideias, sempre sofrendo alterações para melhorar a experiência do usuário. 


### 2. Como a IA Ajudou no Desenvolvimento
- **Resolução de Bugs:** Auxiliou no diagnóstico de erros no console de código e apontou correções de remoçao do JavaScript.
- **Otimização do CSS:** Ajudou a criar regras de *media queries* para garantir a responsividade do layout em dispositivos móveis.
- **Agilidade e Produtividade:** Reduziu o tempo gasto na busca por documentações básicas, estruturando modelos iniciais de código.
- **Melhoria da Documentação:** Ajudou a organizar o raciocínio técnico para elaborar um registro claro das etapas do projeto.
