# 🚀 [Pet love]

## 📌 Descrição do Projeto
[Esta é uma aplicação web desenvolvida com intuito ficticio de adoção de animais, permitindo ao usuário escolher, preencher formulários, com links diretos para rede social com intuito de incentivar a adoção, com descritivos claros e fofos de pets.]

## 🤖 Documentação do Uso de Inteligência Artificial (IA)

### 1. Prompts
Durante a criação do projeto, a IA foi utilizada para auxiliar na resolução de problemas, estruturação do código e complementação de ideias, sempre sofrendo alterações para melhorar a experiência do usuário. 

Prompt enviado para IA:
Quero que você crie um projeto completo de uma Landing Page responsiva para uma plataforma fictícia de adoção de animais chamada Match Pet.
O conceito do projeto deve ser inspirado em aplicativos de relacionamento, como o Tinder, mas voltado para a adoção de animais. A ideia é criar uma experiência onde os usuários possam conhecer cachorros e gatos através de perfis e encontrar um pet que combine com eles, criando um verdadeiro "match" entre pessoas e animais.
Objetivo do projeto:
Criar uma pagina moderna, responsiva, acessível e visualmente atrativa para incentivar a adoção responsável de cachorros e gatos.

Quero que contenha fotos dos pets,cards estilo tinder, centralizados. 
Botões de ação ao clicar no coração
Aparencia sofisticada
Navegação mais simples
Não quero caixas retangulares, queria mais quadradas, simples, com bordas arredondadas

Paleta #febf97

Microdetalhes visuais: linhas, círculos, badges, números, elementos flutuantes

Formulário com aparência de produto real, de adoção real

E principalmente: menos “site de atividade escolar” e mais “landing page de aplicativo que eu poderia colocar no ar”. O site deve transmitir uma aparência fofa, acolhedora e amigável, mas também ter um toque profissional, moderno e direto, evitando um visual exageradamente infantil. Quero que você centralize as fotos e o texto no site.

### 2. Como a IA Ajudou no Desenvolvimento
- **Resolução de Bugs:** Auxiliou no diagnóstico de erros no console de código e apontou correções de remoçao do JavaScript.
- **Otimização do CSS:** Ajudou a criar regras de *media queries* para garantir a responsividade do layout em dispositivos móveis.
- **Agilidade e Produtividade:** Reduziu o tempo gasto na busca por documentações básicas, estruturando modelos iniciais de código.
- **Melhoria da Documentação:** Ajudou a organizar o raciocínio técnico para elaborar um registro claro das etapas do projeto.
